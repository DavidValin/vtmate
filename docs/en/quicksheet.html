vtmate

CONVERSATIONMODE

In this mode, the user speaks via microphone and the ai agent replies. The user can interrupt the agent by speaking on top of his response. During the conversation, the user can change the agent, or start a new conversation.

KEYBOARD

PTT MODE
SPACE (push to talk) records audio until space is released
ESCAPE (press once) stops current response
ESCAPE (press twice) restart the session with no history
U undo last response
CONTROL + S open agents settings popup
CONTROL + E open export popup (to save session)
ARROW LEFT/RIGHT swap to previous / next agent in settings file
ARROW UP/DOWN increase / decrease voice speed in next agent turn
CONTROL + D switches to debate mode
CONTROL + C exits program
LIVE MODE
SPACE (press once) pause/resume user recording
ESCAPE (press once) stops current response
ESCAPE (press twice) restart the session with no history
U undo last response
CONTROL + S open agents settings popup
CONTROL + E open export popup (to save session)
ARROW LEFT/RIGHT swap to previous / next agent in settings file
ARROW UP/DOWN increase / decrease voice speed in next agent turn
CONTROL + D switches to debate mode
CONTROL + C exits program

DEBATEMODE

In this mode, the user gives a subject and 2 agents initialize a debate. The user can participate too.

KEYBOARD

PTT MODE
SPACE (push to talk) records audio until space is released
ESCAPE (press once) pause debate until next user input
ESCAPE (press twice) restarts the debate with no history
U undo last response
CONTROL + S open agents settings popup
CONTROL + E open export popup (to save session)
ARROW UP/DOWN increase / decrease voice speed in next agent turn
CONTROL + D switches to conversation mode
CONTROL + C exits program
LIVE MODE
SPACE (press once) pause/resume user recording
ESCAPE (press once) pause debate until next user input
ESCAPE (press twice) restarts the debate with no history
U undo last response
CONTROL + S open agents settings popup
CONTROL + E open export popup (to save session)
ARROW UP/DOWN increase / decrease voice speed in next agent turn
CONTROL + D switches to conversation mode
CONTROL + C exits program

READMODE

This mode reads a text file with voice, phrase by phrase, highlighting the current phrase.

KEYBOARD

SPACE pause/resume reading
ARROW UP move to the previous phrase
ARROW DOWN move to the next phrase
CONTROL + C exits program

BACKGROUNDMODE

When vtmate runs in background mode you can use the next functionality from anywhere in your computer. No need to be focused in the terminal. To start the background mode use vtmate --daemon

KEYBOARD

CTRL + ALT + A push to talk, ask the agent by voice
CTRL + ALT + R select text, then read it aloud
CTRL + ALT + S push to talk, paste speech as text
CONTROL + Q (press once) stops current speech
CONTROL + Q (press twice) resets the conversation
SETTINGS FILES
~/.vtmate/agentsagents definition file
~/.vtmate/settingsglobal shortcuts (daemon mode)
CLI OPTIONS
-a <agent_name>set a specific initial agent
-p <prompt>initialize with a text prompt
-i <file.txt>initialize with a file prompt
-i –initialize with prompt from STDIN
-qproduce a single response and exit
(requires `-p` or `-i` options)
-ssave the conversation to text and audio file in
~/.vtmate/conversations or ~/.vtmate/read-files
--save-htmlsave conversation as html player + audio per turn
(also accepted as -s-html)
--debate <AGENT1> <AGENT2> [SUBJECT]start debate from text
--debate <AGENT1> <AGENT2> -i <FILE>start debate from text file
--debate <AGENT1> <AGENT2> -i –start debate from stdin text
--max-turns <N>end the program after N debate turns
-r <file.txt>read a file with voice, phrase by phrase (no llm)
-r –read text from STDIN with voice, phrase by phrase
-c <agents_file>use a specific agents file instead of
~/.vtmate/agents
--list-voiceslist all voices for all languages and tts systems
--ptt <true/false>override for this session the ptt setting for all
agents independently of its settings
--daemonstart vtmate in the background
(global hotkeys, voice only)
--daemon-stopstop the running daemon
--daemon-statusshow whether a daemon is running
and its hotkeys
--clone-voice <NAME> <LANG> <WAV> <REF_TEXT>train new voice from .wav
--refine-voice <NAME> <LANG> <WAV> <REF_TEXT>refine an existing voice
--versionprint version
--nbdo not render the vtmate banner
--verboserun the program in verbose mode
--helpshow help
